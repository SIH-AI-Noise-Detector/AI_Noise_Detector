PROJECT SUMMARY
AI/ML Enabled Adaptive Noise Cancellation for Defence Communications

1. PROJECT OBJECTIVE

The project develops an AI/ML-based adaptive noise cancellation system for suppressing environmental noise while maintaining speech intelligibility in noisy communication environments.

2. DATASET

Clean speech:
Mini LibriSpeech train-clean-5

Environmental noise:
ESC-50

Selected noise categories:
- Helicopter
- Engine
- Siren
- Airplane
- Train
- Chainsaw
- Fireworks
- Car horn

Total clean/noisy audio pairs: 1,013

Dataset split:
Training: 810
Validation: 101
Testing: 102

Sampling rate: 16 kHz
Audio segment length: 2 seconds

3. PREPROCESSING

Short-Time Fourier Transform (STFT) is used to convert the noisy audio into a time-frequency representation.

Configuration:
FFT size: 512
Hop length: 128
Window: Hann

The model uses real and imaginary STFT components.

Model input shape:
(1, 2, 257, 251)

4. AI MODEL

The current prototype uses a CNN + GRU based speech enhancement architecture.

Pipeline:

Noisy Audio
    |
    v
STFT
    |
    v
CNN Encoder
    |
    v
GRU Temporal Processing
    |
    v
CNN Decoder
    |
    v
Enhanced STFT
    |
    v
ISTFT
    |
    v
Enhanced Audio

The model was trained using PyTorch.

5. TRAINING

The model was trained using GPU acceleration.

Training loss:
L1 loss on the complex STFT representation.

Trained model:
models/dccrn_basic.pth

6. AUDIO ENHANCEMENT

The trained model was used to process noisy speech and reconstruct enhanced audio using inverse STFT.

Example output:
outputs/enhanced.wav

7. ONNX CONVERSION

The trained PyTorch model was exported to ONNX.

ONNX model:
models/dccrn_basic.onnx

ONNX model size:
33 MB

8. RKNN DEPLOYMENT

The ONNX model was converted using RKNN Toolkit2 version 2.3.2 for the RK3588 target.

FP16 RKNN model:
models/dccrn_basic.rknn

FP16 RKNN model size:
24 MB

9. INT8 QUANTIZATION

A calibration dataset containing 100 representative STFT tensors was generated.

Calibration tensor shape:
(1, 2, 257, 251)

The model was successfully quantized to INT8 and exported as an RKNN model.

INT8 model:
models/dccrn_basic_int8.rknn

INT8 model size:
22 MB

The INT8 RKNN model was successfully loaded using RKNN Toolkit2.

12. CURRENT LIMITATIONS

The current implementation is a prototype.

Actual RK3588 hardware inference has not yet been performed because physical RK3588 hardware is required for runtime testing.

Hardware-level latency, power consumption, NPU utilization and real-time performance therefore remain to be measured.

The current test-set SNR evaluation also indicates that additional model optimization and validation are required before claiming final speech-enhancement performance.
